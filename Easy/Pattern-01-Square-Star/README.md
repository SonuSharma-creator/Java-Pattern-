# Pattern 01 - Square Star 

## Problem

Write a Java program to print a **5 × 5 square pattern** using stars (`*`).

## Program Output :

```text
 *  *  *  *  * 
 *  *  *  *  * 
 *  *  *  *  * 
 *  *  *  *  * 
 *  *  *  *  * 
```

## Concepts Used

* Nested `for` loops
* Rows and columns
* Pattern printing
* Java `System.out.print()`

## Logic

* The **outer loop** controls the number of rows.
* The **inner loop** controls the number of stars in each row.
* Since the pattern has **5 rows and 5 columns**, both loops run 5 times.
* After printing 5 stars, move to the next line using `System.out.println()`.

## Java Solution

See [`Pattern01.java`](./Pattern01.java)

## Complexity

**Time Complexity:** `O(n²)`

**Space Complexity:** `O(1)`
