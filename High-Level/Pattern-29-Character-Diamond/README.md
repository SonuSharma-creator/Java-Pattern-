# Pattern 29 - Character Diamond

## Problem

Write a Java program to print a **character diamond pattern** where alphabets are printed in increasing order in each row, forming a diamond shape.

## Pattern

For `n = 5`:

```text
        A
      A B C
    A B C D E
  A B C D E F G
A B C D E F G H I
  A B C D E F G
    A B C D E
      A B C
        A
```

## Concepts Used

* Nested `for` loops
* Pattern printing
* Character data type
* Type casting
* ASCII character values
* Space management
* Diamond pattern
* Increasing and decreasing rows

## Logic

* The pattern is divided into two parts: **Upper Half** and **Lower Half**.
* The upper half increases from `1` to `n` rows.
* The lower half decreases from `n - 1` to `1` rows.
* The first inner loop prints spaces to center-align the characters.
* The second inner loop prints characters in increasing alphabetical order.
* Character values are generated by adding the column position to the ASCII value of `'A'`.
* The lower half follows the same logic in reverse order to complete the diamond.

### Formula Used

```text
Number of characters = 2 × i - 1
Starting character = 'A'
Character = 'A' + j - 1
```

For the lower half:

```text
Rows = n - 1 down to 1
Number of characters = 2 × i - 1
```

Where:

* `n` = total number of rows in the upper half
* `i` = current row
* `j` = character position

### Loop Relationship

```text
Upper loop → Controls increasing rows
Lower loop → Controls decreasing rows
First loop → Controls spaces
Second loop → Controls characters
```
